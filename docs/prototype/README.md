## 查看方式

检出本分支后，在现代桌面浏览器中打开本目录下的 `koala-ui-prototype-v2.html`。

需要通过本机 HTTP 查看时，可在仓库根目录执行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory docs/prototype
```

然后访问 `http://127.0.0.1:8000/koala-ui-prototype-v2.html`；查看完成后按 Ctrl+C 停止服务。

原型原始格式为 HTML 交互片段。基础页面和点击逻辑不依赖应用后端；Lucide 图标与 Tweak 设计调节入口由对话展示环境提供，独立浏览器中不会显示这些可选元素。主题、密度和首页布局仍可在原型的设置页比较。GitHub 的文件页面用于查看源码，不会执行 HTML 原型。

## 建议走查

1. 在概览切换「默认模式 / 虚拟网卡模式」，分别体验启用、停用及运行中切换的确认弹窗。
2. 修改「出站模式」，查看规则、全局和直连的说明。
3. 切换节点、搜索、排序及测速，返回概览查看对应节点。
4. 在订阅页添加示例订阅、编辑、更新、切换或删除，并检查空态。
5. 查看连接详情、断开样例连接；添加自定义规则；在日志页查看原型操作记录。
6. 在内核页体验模拟重启，在设置页切换主题并观察页面变化。

## 评审边界

- 所有节点、流量、连接和测速均为示例数据；按钮不会修改系统代理、请求订阅或启动真实内核。
- 原型为布局和交互参考，不是生产组件或代理功能验证工具。
- 场景调节、固定更新周期、模拟延迟和内存状态不构成产品需求。运行中模式切换、规则作用域、日志暂停行为等未决项，以 Issue #1 的最终决定为准。
- 图标缺失时仍可依据文字标签走查；完整视觉及跨平台效果需在实现阶段补充验证。
