# [Feature] 重构 Koala Clash 桌面 UI

GitHub：[Issue #1](https://github.com/Pipimax36/Koala/issues/1)

## 要解决的问题与使用场景

希望基于 V2 原型重新设计 Koala Clash 的桌面界面，统一各页面的布局和交互，让用户更容易查看代理状态、切换节点和管理订阅；遇到连接、测速或订阅更新失败时，能看懂当前状态并找到下一步操作。

### 期望效果

- 首页突出代理状态、当前节点和当前订阅，提供清晰的启用、停用及节点切换入口。
- 代理模式使用「默认模式」「虚拟网卡模式」两个 Tab；选择模式与启用代理的状态清晰可辨。
- 将「流量路由」统一命名为「出站模式」，提供规则、全局、直连选项，与代理模式独立选择。
- 节点、订阅、连接、规则、日志、内核和设置页采用一致的导航、列表、表单与反馈方式。
- 保留已有功能、配置和使用习惯，包括主题、订阅导入与排序、托盘、侧栏折叠及高级设置入口。

### 设计参考与范围

设计参考：[Koala UI Prototype V2](./prototype/koala-ui-prototype-v2.html)，[查看说明](./prototype/README.md)。原型用于说明布局和交互，其中的示例数据和演示场景不属于正式功能。

本需求覆盖概览、代理节点、订阅管理、连接、规则、日志、内核、设置 8 个页面的 UI 重构；是否分期交付待确认。本次聚焦桌面端体验，不涉及更换代理内核、新增账号/付费体系或移动端。

## 验收标准

- [ ] **首页与模式**：首页能看到代理状态、当前订阅和对应策略组的节点；代理模式以「默认模式 / 虚拟网卡模式」Tab 展示，出站模式独立切换。未启用代理时，选择 Tab 不会自动连接。
- [ ] **状态反馈**：启用、停用、切换过程中有明确反馈并防止重复操作；失败后显示实际状态和可用的恢复入口，不显示虚假的成功结果。首页、设置和托盘状态保持一致。
- [ ] **节点选择**：可浏览策略组、搜索和排序节点、对单个节点或整组测速；未测试、测试中、有效延迟、超时可区分。切换节点后对应页面同步；预览备用订阅不改变当前节点。
- [ ] **订阅管理**：添加/导入、编辑、更新、切换、删除和排序可用；当前订阅标识明确；导入失败保留输入，更新失败保留已有配置，删除最后一份订阅后显示添加引导。
- [ ] **连接与日志**：连接可搜索、查看详情及断开单个/全部连接；暂停列表刷新不影响网络。日志可搜索、按级别筛选，暂停和清空的作用范围有明确说明。
- [ ] **规则**：可查看规则来源、匹配内容和出站策略，管理自定义规则；无效输入有提示，保存后显示实际生效结果，订阅更新不会意外丢失用户规则。
- [ ] **内核与设置**：内核状态、重启和配置变更有成功/失败反馈；无效端口或权限不足时有明确提示。外观、启动及窗口偏好保存后重启仍保留，原有配置和高级功能继续可用。
- [ ] **异常与空态**：无订阅、无有效节点、搜索无结果、订阅到期和缺失用量信息均有合理展示与后续操作；不能把缺失用量显示成无限额度，也不能把代理已启用等同于互联网已连通。
- [ ] **视觉与可用性**：页面布局和主要交互与确认后的 V2 原型一致；浅色、深色、跟随系统主题及中英文可用；最小窗口、长文案和大列表下，内容可读、主要操作可达。主要操作支持键盘，焦点和选中状态清晰。
- [ ] **功能保留**：原有连接时长/上下行信息、公告与支持入口、订阅排序、侧栏折叠、托盘和高级设置仍可使用。

### 待确认

- 8 页是否分期交付，以及本次验收的桌面平台范围。
- 已连接时切换代理模式是否采用原型中的“确认后切换并恢复”，以及删除当前订阅后停用/切换的规则。
- 自定义规则的作用范围和优先级；日志暂停、清空影响哪些记录。
- 首页布局和信息密度是否提供给用户选择，以及已有自定义主题的兼容范围。
